# Alumnos que contribuyeron

Cada archivo de esta carpeta es el primer pull request de alguien.

Para agregar el tuyo crea `clase-github/alumnos/tu-usuario.md` en tu fork, con tu reto favorito de la Arena, por qué te gusta y el número de tu issue. Sin datos personales: ni nombre completo, ni colegio, ni ciudad, ni fotos.
